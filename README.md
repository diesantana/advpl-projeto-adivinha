# 🎮 Jogo Adivinha (ADVPL)

Projeto desenvolvido em ADVPL com o objetivo de praticar lógica de programação no ambiente Protheus.

## 📌 Sobre o projeto

O **Jogo Adivinha** consiste em um jogo onde o sistema gera um número aleatório e o usuário deve adivinhar com base em dicas fornecidas (maior ou menor).

Este projeto foi desenvolvido como parte dos estudos no curso *ADVPL - Aprenda do Zero (Udemy)*.

## 🚀 Funcionalidades

* Seleção de nível de dificuldade:

  * Fácil (1 a 50)
  * Normal (1 a 100)
  * Difícil (1 a 200)
* Geração de número aleatório
* Feedback a cada tentativa:

  * Número maior ou menor
* Contador de erros
* Mensagem final ao acertar

## 🧠 Conceitos aplicados

* Estruturas de decisão (`If`, `Do Case`)
* Laços de repetição (`While`)
* Funções em ADVPL
* Interação com usuário (`FWInputBox`, `MsgInfo`)
* Manipulação de variáveis

## ▶️ Como executar

1. Compile o programa no ambiente Protheus
2. Execute a função:

```
U_ADIVINHA()
```
