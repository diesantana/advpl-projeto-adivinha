# Jogo Adivinha

Adivinha é um desafio de lógica de programação em ADVPL que consiste em criar um Jogo onde o usuário deve adivinhar um número aleatório gerado pela função Randomize(). 

## Sobre
O objeto é aplicar os conhecimentos em lógica de programação, adiquiridos no curso ADVPL - Aprenda do Zero (Udemy).
